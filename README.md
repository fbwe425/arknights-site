# 明日方舟｜罗德岛战术档案

一个面向《明日方舟》的响应式静态展示网站，提供游戏概览、干员图鉴与可交互的塔防演练。

> 非官方同人展示项目。游戏名称、人物、立绘及相关素材权利归 Hypergryph / Yostar 所有。

## 页面内容

- **首页**：网站简介、游戏基本信息、世界观与核心玩法概览。
- **干员图鉴**：收录 12 名干员，可按职业筛选；角色卡使用明日方舟 Wiki.gg 收录的官方游戏立绘链接。
- **战术演练**：浏览器内运行的轻量塔防小游戏，包含费用回复、部署、自动攻击、战术超载技能与胜败判定。

## 使用方式

这是一个无构建步骤的单页静态网站。

```bash
# 克隆仓库
git clone https://github.com/fbwe425/arknights-site.git
cd arknights-site

# 使用 Python 启动本地预览
python3 -m http.server 8765
```

随后在浏览器访问：<http://127.0.0.1:8765>

也可以直接打开 `index.html`。

## 技术特点

- 原生 HTML、CSS 与 JavaScript，无外部构建依赖
- CSS Grid 与媒体查询实现桌面端、手机端适配
- 触摸与鼠标均可操作塔防棋盘
- 干员职业筛选与页面导航均在前端完成
- 遵循 `prefers-reduced-motion`，降低动态效果对敏感用户的影响
